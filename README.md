# タグパレット

よく使うハッシュタグや文を登録しておき、タップで Twitterの投稿画面に入力する PWA。iPhone / Android 両対応。

**▶ アプリを開く：<https://mbs-code.github.io/tag-palette/>**

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（画面・保存・エクスポート/インポート） |
| `manifest.json` | ホーム画面に追加したときの名前・アイコン・共有メニューへの登録 |
| `sw.js` | オフラインでも開けるようにするキャッシュ |
| `version.js` | バージョン（キャッシュ名と設定画面の表示） |
| `ogp.png` | リンクを共有したときのカード画像（OGP）。画像を変えたら `index.html` の `og:image` の `?v=` の数字を上げる（アプリ内の表示にも同じ番号が付く） |
| `icon*.png` / `icon.svg` | アイコン（`icon-maskable-*` は Android 用、`icon-180` は iPhone 用で角まで塗りつぶし） |

`.claude/` フォルダはローカル確認用なのでアップロード不要です。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（例：`tag-palette`、Public）
2. 上のファイルをリポジトリ直下にアップロード（「Add file → Upload files」でドラッグでOK）
3. リポジトリの **Settings → Pages** を開く
4. **Source: Deploy from a branch**、**Branch: main / (root)** を選んで Save
5. 1〜2分待つと `https://<ユーザー名>.github.io/tag-palette/` で公開される

## スマホに入れる

アプリの **⚙ 設定 →「ホーム画面に追加」** からも追加できます（Android / PC の Chrome・Edge はそのままインストール画面が開き、iPhone は手順が表示されます）。


- **iPhone**：Safari で上のURLを開く → 共有ボタン → 「ホーム画面に追加」
- **Android**：Chrome で開く → メニュー（︙）→ 「ホーム画面に追加」または「アプリをインストール」

## 使い方

- 右下の **＋** でパレット（カード）を追加（入力欄の中で `#タグ` や URL が青字になる）
  - グループ欄を押すと、欄の下に出るメニューでグループを選べる（新しいグループ名の入力もここで。未分類も選べる）
- パレットを **タップ** → 設定した動作（Twitterを開く / コピー）
- パレットを **長押し** → 編集画面（編集・グループ変更・Twitterを開く・コピー・有効/無効・削除。一番下に更新日と、どれくらい前か）
  - 無効にしたパレットはグレーになり、タップしても何も起きない（長押し・並べ替えはできる）
- 右端の **≡** をドラッグ → 同じグループの中で並べ替え
- 右上の切り替えで並べ方を選べる：**グループ順**（いつもの一覧）／**利用順**（グループに関係なく、最後に使った順。直近（1時間以内）・今日・今週・今月・それ以前・未使用の見出しで分ける。並べ替えの ≡ は出ない）。選んだ並べ方は次回も続く
- 一覧はグループごとにまとめて表示。右上の **グループ** ボタン（重なった板のアイコン）でグループ一覧を開き、≡ のドラッグで並び順を変えられる。カードをタップすると名前・色（12色のプリセット、または虹色の丸から自由に）を変えたり、グループを中のパレットごと削除したりできる（同じ名前にすると2つのグループをまとめる。未分類に名前を付けると、中のパレットがそのグループに移る）。色はカードの左の縦線になる
- **⚙** から
  - タップしたときの動作：Twitterを開く / コピー / 編集画面を開く（Twitterを開く・コピーもそこからできる）
  - テーマ（自動 / ライト / ダーク）
  - 使い方をもう一度表示（× で閉じた「使い方」を戻す）
  - 初期状態に戻す（すべてのパレットと設定を削除）
  - バックアップの書き出し・読み込み（パレットの作成日・更新日・利用回数・有効/無効と設定もまるごと移せる。「置き換え」か「追加」を選択、重複は自動スキップ。旧版のバックアップも読める）

## ほかのアプリから読み込む

- パレットの追加・編集画面の **ツイートから引用** を押すと同じ「ツイートの引用」画面が開き、URLを入れて取り込めます（結果は編集中の本文に入ります）。

- **Android**：ホーム画面に追加（インストール）すると、共有メニューに「タグパレット」が出ます。Twitter のツイートなどを共有して選ぶと「ツイートの引用」画面が開き、次から選べます。
  - タグだけ取り出す（1行に1つ）
  - タグだけ取り出す（横に並べる）… スペース区切り
  - 全文をそのまま使う
  
  選ぶと、その内容でパレットの作成画面が開きます。※ Twitter アプリの「共有」はツイートのリンクだけを送ってくるため、Twitter の埋め込み用 API（oEmbed）でツイートの本文を取得して読み込みます。長いツイート（280字を超えるもの）は途中までしか取得できません。鍵アカウントや削除されたツイートは取得できません。
- **iPhone など**：共有メニューへの登録には対応していないため、`?text=` を付けて開くと同じ「ツイートの引用」画面が出ます（ショートカット App の「URLを開く」などから）。
  例：`https://mbs-code.github.io/tag-palette/?text=%23番組名%20%23実況タグ`（`title` / `url` も使えます）

## 注意

- データは端末のブラウザ内に保存されます。Safari の「履歴とWebサイトデータを消去」で消えるので、定期的にエクスポートしておくと安心です。
- iPhone では Safari とホーム画面版でデータが別になります。ホーム画面に追加してから使い始めてください（既にSafariで登録済みならエクスポート→インポートで移せます）。
- アプリを更新したときは、`version.js` の `APP_CACHE`（例：`tag-palette-rev126` → `tag-palette-rev127`）と `APP_RELEASED`（日付）を書き換えてください。キャッシュ名と、設定画面の「2026-11-21 rev126」の表示の両方に使われます。

## データの保存とアクセス解析について

パレットや設定などのアプリのデータは、端末（ブラウザ）の中にだけ保存され、サーバーには送られません。ツイートを引用するときだけ、本文を取得するためにそのツイートのURLを Twitter（X）に送ります。

このサイトでは利用状況を把握するために Google タグマネージャー（Google アナリティクス）を使用しています。Cookie を使って匿名のデータを収集しますが、個人を特定する情報は含みません。データの扱いについては [Google のポリシー](https://policies.google.com/technologies/partner-sites?hl=ja) をご覧ください。アプリ内でも設定画面の「このアプリについて」→「データの保存とアクセス解析について」に同じ内容を表示しています。
